# Video script draft — Meridian Foundation

## Opening

This project builds an educational decision-support dashboard for the Meridian
Foundation. The analysis uses the mandate, portfolio assumptions, price file,
and DGS10 data card from prior course labs. The dashboard distinguishes
classroom assumptions and historical observations from verified forecasts.

## Mandate and baseline comparison

The mandate describes a CPI plus four percent net-of-costs objective over
rolling five-year periods, a seven-year horizon, annual rebalancing, a 60/40
benchmark, and liquidity, reserve, concentration, turnover, and long-only
requirements. The 6.5% figure is a Lab 14 classroom comparison proxy; it is not
a substitute for the actual CPI objective.

The dashboard compares equal weights, the 40% investment-grade / 60% global
equity benchmark, and a transparent constrained candidate. Returns and risk
from the Lab 14 inputs are assumptions. Passing the return proxy and reserve
checks does not mean every mandate requirement is verified.

## Data timing and stress

The historical ETF summaries are descriptive and depend on the supplied data
and estimation window. The DGS10 series remains quarantined because only a few
vintage checks are available. The release-time control illustrates why a
same-day observation cannot be used before its stated 4:15 p.m. Eastern release.

The scenario controls let us explore assumption changes, historical windows,
costs, constraints, and stop conditions. Those scenarios are not proof of
future performance.

## Recommendation

The current recommendation is no pilot authorization because material
evidence and mandate questions remain open. A 5%–10% pilot sleeve is only a
possible future committee discussion after the specified data, compliance,
validation, and CIO gates are met. This is not an investment recommendation.
